### 💡 Engineering Vision
I build the brains behind connected hardware. My focus is on the intersection of **Bare-metal/RTOS firmware, EV micro-mobility, and edge computing**. I believe in hardware-software co-design: writing lightweight, efficient C/C++ code that maximizes the potential of microcontrollers while seamlessly integrating with global IoT networks via protocols like MQTT and LTE.

### 🚀 What I'm Shipping Right Now
- **E-Bike Infrastructure:** Architecting firmware and PCB layouts for the **HOOK UNIQ** and **HOOK DAILY** motor-mount conversion systems at Dimension Six Technologies.
- **Advanced Telemetry:** Implementing cadence-sensing algorithms and custom wireless throttle controls using **nRF52** and **ESP32** ecosystems.
- **Secure Systems:** Developing kiosk-based EV charging and swap systems with secure device handoffs and backend integrations.
